# Dev-unlock credentials: rotation + hardening

Date: 2026-08-28
Not committed to the repo (session artifact).

## What changed

`core/dev_access.py` shipped plaintext `DEV_USERNAME = "michaeltsmith2007"` /
`DEV_PASSWORD = "tofee232"`, compared directly in `check_credentials()` and
`grant_access()`.

Now:

- **New built-in login: `dev` / `password`.**
- `DEV_PASSWORD` is gone. The password is stored as **PBKDF2-HMAC-SHA256**:
  - `_DEV_PW_SALT = "c7e4ed9e19e73970fe8bab97f341c56e"` (random 16 bytes)
  - `_DEV_PW_HASH = "a1c9fb6e8d2d369e38ab3850198a241caf5f0b9f7d123ca4fcb50f246d0288ea"`
  - `_DEV_PW_ITERS = 200000`
  - Generated by actually running Python; stdlib only (`hashlib`, `secrets`, `hmac`).
- New helpers: `_verify(password, salt_hex, hash_hex, iters)` (constant-time via
  `hmac.compare_digest`), `_pbkdf2()`, `_new_entry()`, `_verify_entry()`.
- `check_credentials()` built-in path: `username == DEV_USERNAME and _verify(...)`.
- `grant_access()` gates on `_verify(granter_password, _DEV_PW_*)`.
- **Granted accounts** now stored as `{"salt", "hash", "iters"}` per entry (random
  salt each). **Backward compatible**: old `{"password_hash": "<fixed-salt sha256>"}`
  entries in an existing `dev_access.json` still verify via the retained `_hash()`.
- A comment block above `_DEV_PW_HASH` documents the login and a one-liner to
  regenerate the salt/hash/iters.
- `gui/app.py`: the stale `DEV_USERNAME / DEV_PASSWORD` comment updated (no code
  change - it only ever imported `check_credentials` / `grant_access`).
- New `docs/DEV_ACCESS.md`.

## Archived releases

GitHub releases v1.0-v1.5.2 are immutable artifacts and still contain the old
plaintext credentials in their source zips. They cannot be rewritten. The repo
must remain **private** regardless - salt, hash, and iteration count are all in
source, so a weak password could be brute-forced offline by anyone with a clone.

## How to recover / change the built-in password

Login: `dev` / `password`.

To set a new password, run:

```
py -3 -c "import secrets,hashlib; s=secrets.token_bytes(16); i=200000; print('salt=',s.hex()); print('hash=',hashlib.pbkdf2_hmac('sha256', input('new password: ').encode(), s, i).hex()); print('iters=',i)"
```

Paste the three printed values into `_DEV_PW_SALT` / `_DEV_PW_HASH` /
`_DEV_PW_ITERS` in `core/dev_access.py`. Username is the plain `DEV_USERNAME`
constant in the same file. Also documented in `docs/DEV_ACCESS.md`.
